# S3 Guide — Create, Upload, Download, Delete

## Key Info
- **Region:** `us-west-2`
- **Profile:** `pnnl`

---

## Create a Bucket (one-time)

```bash
aws s3 mb s3://pnnl-s3 \
  --region us-west-2 \
  --profile pnnl
```

> Bucket names must be globally unique across all AWS accounts.
> Use something like `pnnl-tongfei-ml-models` to avoid conflicts.

Verify it was created:

```bash
aws s3 ls --profile pnnl
```

---

## Upload Files

### Upload a single file

```bash
aws s3 cp local_file.pth s3://pnnl-s3/folder/local_file.pth \
  --region us-west-2 \
  --profile pnnl
```

### Upload a whole folder

```bash
aws s3 cp ./my_folder s3://pnnl-s3/my_folder \
  --recursive \
  --region us-west-2 \
  --profile pnnl
```

---

## Download Files

### Download a single file

```bash
aws s3 cp s3://pnnl-s3/folder/local_file.pth ./local_file.pth \
  --region us-west-2 \
  --profile pnnl
```

### Download a whole folder

```bash
aws s3 cp s3://pnnl-s3/my_folder ./my_folder \
  --recursive \
  --region us-west-2 \
  --profile pnnl
```

## List Bucket Contents

```bash
# List top level
aws s3 ls s3://pnnl-s3 --profile pnnl

# List a specific folder
aws s3 ls s3://pnnl-s3/models/ --profile pnnl
```

---

## Delete Files

### Delete a single file

```bash
aws s3 rm s3://pnnl-s3/folder/local_file.pth \
  --profile pnnl
```

### Delete a whole folder

```bash
aws s3 rm s3://pnnl-s3/my_folder \
  --recursive \
  --profile pnnl
```

### Delete the entire bucket (irreversible)

```bash
# Must empty it first
aws s3 rm s3://pnnl-s3 --recursive --profile pnnl

# Then delete the bucket
aws s3 rb s3://pnnl-s3 --profile pnnl
```

## Use S3 from Python (boto3)

### Upload

```python
import boto3

s3 = boto3.client('s3', region_name='us-west-2')
s3.upload_file('cifar10_v2.pth', 'pnnl-s3', 'models/cifar10_v2.pth')
print("Uploaded!")
```

### Download

```python
import boto3

s3 = boto3.client('s3', region_name='us-west-2')
s3.download_file('pnnl-s3', 'models/cifar10_v2.pth', 'cifar10_v2.pth')
print("Downloaded!")
```

### List files in a folder

```python
import boto3

s3 = boto3.client('s3', region_name='us-west-2')
response = s3.list_objects_v2(Bucket='pnnl-s3', Prefix='models/')
for obj in response.get('Contents', []):
    print(obj['Key'], obj['Size'])
```

## CIFAR-10 Model Workflow

### After training — save model to S3

```bash
# Inside SSM session on EC2
aws s3 cp ~/cifar10/cifar10_v2.pth \
  s3://pnnl-s3/models/cifar10_v2.pth \
  --region us-west-2
```

### Next session — restore model from S3 to EC2

```bash
# Inside SSM session on EC2
aws s3 cp s3://pnnl-s3/models/cifar10_v2.pth \
  ~/cifar10/cifar10_v2.pth \
  --region us-west-2
```

### Download model to your Mac

```bash
# On your local Mac
aws s3 cp s3://pnnl-s3/models/cifar10_v2.pth \
  ~/Desktop/cifar10_v2.pth \
  --profile pnnl \
  --region us-west-2
```

## Quick Reference

| Task | Command |
|------|---------|
| Create bucket | `aws s3 mb s3://BUCKET --region us-west-2 --profile pnnl` |
| List buckets | `aws s3 ls --profile pnnl` |
| Upload file | `aws s3 cp FILE s3://BUCKET/path --profile pnnl` |
| Download file | `aws s3 cp s3://BUCKET/path FILE --profile pnnl` |
| List contents | `aws s3 ls s3://BUCKET/ --profile pnnl` |
| Delete file | `aws s3 rm s3://BUCKET/path --profile pnnl` |
| Delete folder | `aws s3 rm s3://BUCKET/folder --recursive --profile pnnl` |
